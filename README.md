# KranProtokoll – Web-App (Testversion)

Montage-, Übergabe- und Abnahmeprotokolle für Turmdrehkrane, Zeiterfassung und Suche in Anleitungen.

**Öffnen:** https://liam-alimonta.github.io/kranprotokoll-app/
Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Alle Daten bleiben auf dem jeweiligen Gerät.
